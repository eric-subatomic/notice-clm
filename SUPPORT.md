# Support

Notice is an open-source, deployable product foundation. Community support is best effort; this repository does not provide a hosted service, customer help desk, emergency production response, or uptime/security-maintenance SLA.

## Where to ask

- Read the [documentation index](./docs/README.md), [complete user guide](./docs/USER_GUIDE.md), and [operations runbook](./docs/OPERATIONS.md).
- Search existing GitHub issues and pull requests.
- Open a bug report for a reproducible repository defect using synthetic data.
- Open a feature request for a focused product, operations, documentation, or contributor proposal.
- Follow [SECURITY.md](./SECURITY.md) for suspected vulnerabilities. Never disclose one in a public issue.

## What to include

Provide the exact release tag or commit SHA, evaluation/staging/production mode, Node and npm versions, the smallest synthetic reproduction, expected and actual behavior, and redacted request IDs or logs. Never paste secrets, environment-variable values, real agreements, customer identifiers, personal information, provider bearer links, or private infrastructure details.

## Production responsibility

Running Notice with real data requires the identity, infrastructure, providers, policy, records controls, monitoring, backup/restore, and acceptance work in [Production setup](./docs/PRODUCTION_SETUP.md). Operators remain responsible for their deployment and incident process. A GitHub issue is not an emergency channel.

Commercial implementation or support arrangements, if any are offered separately, are outside this repository and do not change the MIT license or the project's public support commitments.
